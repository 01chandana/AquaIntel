\\# AquaIntel Production Launch Runbook



\## 1. Purpose



This document explains how to safely deploy, verify, monitor, and roll back AquaIntel.



\## 2. Release Checklist



Before deployment:



\- \[ ] Git working tree is clean

\- \[ ] All tests pass

\- \[ ] Docker image builds successfully

\- \[ ] Environment variables are configured

\- \[ ] Database backup is available

\- \[ ] Health endpoint is available
